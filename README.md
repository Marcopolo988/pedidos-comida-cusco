# 🍽️ Pedidos Comida Cusco

Sistema web para gestionar pedidos de comida local, desarrollado por una startup en Cusco.
Este proyecto es parte del **Laboratorio 1 del curso de Ingeniería de Software** e implementa
control de versiones con Git y GitHub desde el inicio del desarrollo.

---

## Descripción del proyecto

La startup busca ofrecer una plataforma donde los usuarios puedan explorar el menú de
restaurantes locales cusqueños, armar su pedido y realizar el seguimiento del mismo.
El objetivo de esta primera etapa es **organizar el código desde el inicio** usando una
herramienta de control de versiones.

## Objetivos

- Configurar un entorno de desarrollo.
- Aplicar control de versiones con Git.
- Gestionar un repositorio local y uno remoto en GitHub.

## Herramientas utilizadas

- **Visual Studio Code** — editor de código.
- **Git** — control de versiones local.
- **GitHub** — repositorio remoto y colaboración.

